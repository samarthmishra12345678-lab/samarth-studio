Step 1

Open Google Cloud

Go to console.cloud.google.com/apis/credentials. Sign in with the Gmail you want as studio owner.

Step 2

Create a project

Top bar project name → New project → name Samarth Studio → Create. Select that project.

Step 3

OAuth consent screen

Left menu: APIs and services → OAuth consent screen (sometimes called Google Auth platform).

User type: External → Create.

App name: Samarth Mishra Web Studio
User support email: your Gmail
Developer contact: your Gmail → Save.

Scopes: keep email, profile, openid (default). Save.

Test users: Add your Gmail. Save. Publishing status can stay Testing while you try it. Later click Publish app so any client can log in.

Step 4

Create Web Client ID

Credentials → Create credentials → OAuth client ID.

Application type: Web application. Name: Studio web.

Authorized JavaScript origins (Add URI), two lines after publish (I will send the exact Vercel URL). For now add:

http://localhost:3000

Leave Authorized redirect URIs empty for Google Identity Services button (we use ID token, not redirect).

Create. Copy Client ID only (ends with .apps.googleusercontent.com). Do not send Client Secret in chat if you can avoid it. We only need Client ID.
